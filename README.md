# N픽 바이오링크

GitHub Pages용 정적 바이오링크 페이지입니다.

## 업로드 방법
1. 저장소 최상위 경로에 `index.html`, `README.md`, `assets/` 폴더를 업로드합니다.
2. GitHub 저장소의 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. `index.html`에서 각 추천 카드의 `href="#"`를 실제 제휴 링크로 교체하고, SNS 주소도 실제 계정 주소인지 확인합니다.

## 포함 파일
- `index.html`: 반응형 바이오링크 페이지 및 검색/공유 기능
- `assets/npick-profile.png`: N픽 프로필 이미지
- `assets/info.jpg`, `hotel.jpg`, `childcare.jpg`, `gift.jpg`, `holiday-gift.jpg`: 추천 카드 이미지

※ 추천 카드의 `#` 링크는 실제 제휴 링크가 아닙니다. 공개 전에 교체하세요.
